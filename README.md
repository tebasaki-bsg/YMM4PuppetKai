# パペット変形改（YMM4PuppetKai）

製作者：Tebasaki
配布場所：https://github.com/tebasaki-bsg/YMM4PuppetKai/releases
作品ID（ニコニコの親作品登録）：nc516642

## 概要

ゆっくりMovieMaker4（YMM4）の映像エフェクトに「改パペット変形」を追加するプラグインです。
YMM4 に内蔵の「パペット変形」を作り直し、「切れ込み」の機能を加えて軽くしました。画像の上にピンやボーンを置いて動かすと、周りの画像が引っ張られて変形します。

| 機能 | 内容 |
|---|---|
| 切れ込み | 紙に切れ込みを入れるように線を引くと、線の両側が分かれて別々に動きます。折れ線にでき（1本 32 点まで）、1つのエフェクトに 64 本まで置けます |
| ピン | 画像上の点です。動かすと、周りの画像が引っ張られて変形します（256 本まで） |
| ボーン | 関節を親子でつないだ骨組みです。角度・伸縮・揺れで、腕のような物体を関節ごとに動かします（256 本まで） |
| 2つの変形方式 | 剛体（ARAP。形を保つ）と、なめらか（MLS。なめらかに曲がる）。どちらでも切れ込みが効きます |
| 輪郭に沿った網目 | 網目を画像の不透明な部分の輪郭と切れ込みに沿って作るので、切り口がギザギザになりません |
| 精度の切り替え | 剛体（ARAP）の計算の精度を、プレビューの再生中と書き出しで別々に選べます |
| 本体と並べて使える | 本体のパペット変形とは別のエフェクトなので、同じプロジェクトで両方使えます |

## インストール方法

1. [Releases](https://github.com/tebasaki-bsg/YMM4PuppetKai/releases) から `YMM4PuppetKai.ymme` をダウンロードする。
2. YMM4 を終了してから、`YMM4PuppetKai.ymme` をダブルクリックし、表示される画面に従ってインストールする。

## 使用方法

1. YMM4 を起動し、アイテムに映像エフェクト「改パペット変形」（「加工」の中）を追加する。追加したときは、ピンはありません。
2. エフェクトの設定にある編集キャンバスで、ピン・ボーン・切れ込みを画像の上で編集する。
   - 「ピン」タブ：何もない所をクリックでピンを追加、ドラッグで基準位置を移動します。
   - 「ボーン」タブ：何もない所をクリックでボーンを追加（選択中のボーンの子）、ドラッグでジョイントを移動、ボーン間の線をクリックでボーンを挿入、ボーンを選んでピンをクリックで紐付け／解除、右クリックで選択を解除します。
   - 選んだピン・ボーンは、キャンバスの下の欄で移動・角度などを設定します（YMM4 の中間点・アニメーションが使えます）。
   - 削除は、選んでからタブの「−」です。
3. 切れ込みを入れる。
   - キャンバス右上のハサミのボタンで、画像の中央に切れ込みを1本追加します。点はどちらのタブでもドラッグで動かせます。
   - 切れ込みの線をクリックすると、その位置に点が増えて折れ線になります。
   - 中間点は、選んで「−」か右クリックで消せます（始点・終点を選んで「−」は切れ込みごと削除）。
   - 輪郭（緑の線）の外にある端は「開いた端」（四角）、内側にある端は「閉じた端」（丸。そこはつながったまま残ります）です。

### 編集キャンバスの操作

| 操作 | 内容 |
|---|---|
| Ctrl＋ホイール | 拡大縮小 |
| 中ボタンドラッグ | 表示位置の移動 |
| 十字のボタン | 表示を初期化 |
| 円形の矢印のボタン | 表示する画像を読み直す（再生位置を動かしたときは自動で読み直します） |
| 「すべてのピンの移動を 0 に戻す」ボタン | 全ピンの移動X・移動Y を 0 にします |
| キャンバスの下端のドラッグ | キャンバスの高さを変える |

### エフェクトの設定

| 設定 | 初期値 | 内容 |
|---|---|---|
| 変形方式 | 剛体（ARAP） | 剛体（ARAP）：形を保つ／なめらか（MLS）：なめらかに曲がる |
| 剛性 | 2.00 | なめらか（MLS）のときだけ表示。大きいほど、ピンの近くだけが動きます |
| プレビュー精度 | 0.25px | 剛体（ARAP）のときだけ表示。プレビューの再生中に使う計算の精度です |
| 書き出し精度 | 0.02px | 剛体（ARAP）のときだけ表示。書き出しと、プレビューを止めているときに使う計算の精度です |
| ピン・ボーン・切れ込み | なし | 編集キャンバス |

- 精度は 0.02／0.05／0.1／0.25／0.5px から選べます。1回の繰り返しでの形の動きがこの値より小さくなったら計算を止めます。大きいほど速く、形は粗くなります。

### ピン・ボーン・切れ込みの値

| 対象 | 値 | 中間点で変えられるもの |
|---|---|---|
| ピン | 有効、基準X・Y、移動X・Y | 移動X・Y |
| ボーン | 有効、ジョイントX・Y、角度、伸縮、揺れ（揺れ角度・揺れ周期・揺れ位相・揺れ伝播・しなり） | 角度、伸縮、揺れ角度、揺れ周期、揺れ伝播、しなり |
| 切れ込み | 有効、各点の X・Y | なし（位置は固定） |

## アンインストール方法

1. YMM4 を起動して `ヘルプ(H)` > `その他` > `プラグインフォルダを開く` をクリックする。
2. YMM4 を終了する。
3. `YMM4PuppetKai` という名前のフォルダを削除する。

## 注意点

OS：Windows 10 / 11（64bit）
ゆっくりMovieMaker4：v4.57.0.1（Lite）
にて動作確認をしています。

### 本プラグインが作るファイル

ありません。ピン・ボーン・切れ込みはプロジェクトに保存されます。
エラーは YMM4 本体のログ（`YMM4のフォルダ\user\log`）に「パペット変形改：」で始まる行として書かれます。

### 制限事項

- YMM4 のプレビュー画面の上には、ピン・ボーン・切れ込みを表示せず、そこでは編集もできません（編集はエフェクトの設定の編集キャンバスで行います）。
- グループ制御は「画像を合成」がオンのときだけ対応します。
- 本体のパペット変形の設定を取り込む機能はありません。
- AviUtl 向けの出力（exo）には対応していません。

## 開発者向け

### フォルダ構成

```
src/PuppetKai.Core/      YMM4に依存しない計算部分（輪郭・網目・切れ込み・MLS・ARAP・ボーン）
src/YMM4PuppetKai/       プラグイン本体（PuppetKai.Core のソースも取り込んで1つのDLLにする）
  Shaders/               頂点シェーダー・ピクセルシェーダー（HLSL。実行時に YMM4 同梱の D3DCompiler でコンパイル）
tests/PuppetKai.Tests/   計算部分のテスト
dist/                    配布物（.ymme）に入れる README・LICENSE・THIRD-PARTY-NOTICES（txt）
docs/                    仕様書
```

- 網目は、輪郭と切れ込みを辺に含む Delaunay 分割です。切れ込みの線上の頂点は、まわりの三角形を切れ込みの辺で区切ったまとまりごとに分けます（曲がり角・交点は分かれ、輪郭の内側で止まった端はつながったまま）。
- なめらか（MLS）は、網目の頂点ごとに、網目に沿った距離で重みを付けて計算します。剛体（ARAP）は Anderson 加速付きの局所・大域の繰り返しで、連立方程式は RCM で並べたスカイライン形式のコレスキー分解で解きます。
- 描画は Direct2D の自作エフェクトで、変形した網目を「変形前の画像を貼った三角形」として描きます。
- HLSL のソースは ASCII だけにしてください（日本語のコメントがあると、コンパイル時にソースの末尾が切れます）。

### ビルド方法

1. YMM4 のフォルダを `YMM4DirPath` として渡し、ビルドします（末尾の `\` を忘れずに）。

   ```
   dotnet build src/YMM4PuppetKai/YMM4PuppetKai.csproj -c Release -p:YMM4DirPath="C:\YMM4\"
   ```

2. `src/YMM4PuppetKai/bin/Release/net10.0-windows/YMM4PuppetKai.dll` ができます。

`Directory.Build.props` は全プロジェクト共通の設定（言語の版・Nullable・unsafe）で、各自の設定は入っていません。
画面は XAML ファイルを使わずコードで作っており、WPF の DLL は YMM4 のフォルダから直接参照しています。そのため Windows 以外（Linux など）でも配布用の DLL を作れます（必要なのは .NET 10 SDK だけです）。

### テスト

```
dotnet run --project tests/PuppetKai.Tests -c Release
```

YMM4 に依存しない計算部分（`PuppetKai.Core`）のテストです。`--bench` と `--tol` は速さと精度の計測用で、`tests/PuppetKai.Tests/hand_mask.raw`（手の画像の不透明度、560×600）を使います。

### 配布用ファイルの作り方

`YMM4PuppetKai/` フォルダに、ビルドした `YMM4PuppetKai.dll` と `dist/` の3つの txt を入れて zip にし、拡張子を `.ymme` にします。`dist/LICENSE.txt`・`dist/THIRD-PARTY-NOTICES.txt` は、リポジトリのトップの `LICENSE`・`THIRD-PARTY-NOTICES.md` と同じ内容を、配布物用のテキスト（UTF-8 BOM 付き・CRLF）で書いたものです。片方を直したら、もう片方も合わせてください。ファイル名にバージョンを入れないでください（インストール先のフォルダ名になります）。
